AI Shorts Bot

AI Shorts Bot is a private, single-user content creation workflow used by its owner to prepare and upload original short-form videos to the owner's YouTube channel.

The workflow uses the YouTube Data API solely to upload and manage videos authorized by the channel owner through OAuth 2.0. It is not offered as a public service and does not provide third-party accounts or public login access.

The application does not download, copy, redistribute, or modify other creators' YouTube videos.

API Client: AI Shorts Bot
Access: Private / single user
Primary use: Uploading original Shorts to the owner's channel

YouTube API Services: This workflow uses the YouTube Data API v3 for owner-authorized video uploads. Use of YouTube API Services is subject to the YouTube Terms of Service and Google Privacy Policy.
