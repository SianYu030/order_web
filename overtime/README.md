# 業務假日或臨時加班登記網站 · V1.0.2

獨立路徑：\`/order_web/overtime/\`。原本 \`/order_web/\` 報修系統與其他網站頁面不變。

## 已完成

- iPhone / Android / 電腦響應式表單。
- 網站只有「加班時數」和「加班原因／備註」。不提供請假、支援或班別操作；原月表既有三種欄位及班別、便當公式不變。
- 年、月、日、E3、E4、W8、W8整修、E5（含五金／機修／業務／內勤）選擇。
- 展示模式使用**虛構員工**，資料只存在瀏覽器 localStorage，不觸碰公司資料。
- Google Identity Services OAuth 連線介面；正式模式可讀取既有 Google Sheets 人員主檔及月表。
- 以完整工號搜尋月份分頁的 C 欄，依照每日 5 欄定位：請假、加班、支援、日別／班別、便當。
- 寫入時數到選定儲存格，原因寫入相同格的 **Google Sheets 註解（comment）**；支援已有網站註解時更新或回覆。
- 正式寫入前對照原值並再次確認。寫入後讀回驗證時數及註解。
- 便當由原表公式計算；網站不覆蓋便當、月累計及其他統計公式。
- 網站只開放「加班」登記與查詢修改，不提供「請假」、「支援」或「班別」欄位。原月表的請假欄與公式全部保留。
- 歷史月份隱藏頁不允許網站修改，日期的實際年份和表格年份不同時禁止寫入。

## 正式 Google 連線所需條件

目前**尚未取得此公司的 Google OAuth 網頁用戶端 ID**，所以公開頁面預設展示模式。要讓正式連線按鈕可用，需要一次性建立 Google Cloud OAuth：

1. Google Cloud 建立或選擇一個專案、啟用 **Google Sheets API**。
2. 設定 OAuth 同意畫面（公司 Workspace 可依管理政策選擇內部；個人 Google 帳戶可用外部測試使用者）。
3. 建立 OAuth 用戶端，應用程式類型選 **網頁應用程式**。已授權 JavaScript 來源填 **\`https://sianyu030.github.io\`**（不含 \`/order_web\` 路徑）。
4. 把取得的 **OAuth Client ID** 貼到網站「設定」。**不要貼 Client Secret、服務帳戶 JSON、Google 密碼。**
5. 以**有編輯來源試算表權限**的 Google 帳號登入，確認已讀取名冊並顯示正確員工及目的儲存格。
6. 第一次寫入請選擇測試專用資料，由管理人員確認註解與便當公式及統計仍正確。正式操作前需先有來源表版本備份。

**重要限制：** V1.0.0 是「具備試算表編輯權的授權人員」使用的 Google OAuth 直連版。沒有 Google 試算表編輯權限的員工**無法直接把資料送進原表**。不可為了方便而把整張公司試算表設成公開可編輯。如果要讓全廠員工只登入網頁、只能編輯自己的資料，必須再配置具身分驗證與角色權限的私有後端，不能只靠 GitHub Pages 靜態頁面達成。尚未配置該後端。

## 實際資料映射

| 日期（以每月第一日 G 欄為基準） | Offset |
| --- | --- |
| 第 d 日請假 | 6 + 5 × (d - 1)，0 起算 |
| 第 d 日加班 | 7 + 5 × (d - 1) |
| 第 d 日支援 | 8 + 5 × (d - 1) |
| 第 d 日班別 | 9 + 5 × (d - 1) |
| 第 d 日便當 | 10 + 5 × (d - 1)，**僅原表公式負責** |

例如 E5/機修課 2026 年 11 月 16 日的 2693 工號在月表第 25 列：
請假 CD25、加班 **CE25**、支援 CF25、班別 CG25、便當 CH25。

原表的「月份」分頁名稱沒有年份。網站會讀取日期儲存格的實際 Google Sheets 日期序號，驗證完整年、月、日以避免跨年誤寫。舊月份若已隱藏，不提供網站修改。

### 儲存格註解

官方 Google Sheets API 2026-09-30 正式支援\`insertComment\`、\`updateCommentPost\` 等請求。

網站註解的第一段是原本的加班原因，文末為簡短標記：

\`\`\`
文書加班

［加班登記網站］
\`\`\`

標記用來辨別網站產生的註解，避免覆蓋原本由員工手動寫入的留言。已有網站註解會優先更新屬於登入者的文章；其他作者的註解無法直接被覆蓋。因不同人登入產生的回覆可能保留歷史，屬於 Google 原生對話串行為。

**部分成功風險：** API 可能已成功更新時數，但註解儲存失敗。正式版會檢查 \`commentUpdateState\` 及再次讀取註解；若不一致，會提示「部分成功」，不能誤報整筆成功。不能保證整份表中其他依 Apps Script \`onEdit\` 的運算都被觸發，需在正式測試確認。

## 安全

- GitHub 公開 repo 不包含 Google OAuth client secret、存取權杖或員工清單。
- OAuth Client ID 屬於公開用戶端識別碼，僅儲存瀏覽器本機。
- OAuth token 保存在當前分頁記憶體，不寫入 GitHub/localStorage。
- Google Sheets 編輯與註解 API 權限由 Google 帳號控制。
- 前端程式開源並不能防止具有整張表編輯權限的使用者透過其他方式修改整張表；細分角色權限需私有後端。
